# Security

Please report security issues privately through the repository's GitHub security
advisories if private reporting is available. Otherwise, contact the maintainer
through their public GitHub profile to arrange a private channel before sharing
details. Do not put signed media URLs, session cookies, credentials, or private
recordings in a public issue.

Run the tool with normal user permissions. Keep external media tools updated and
process only media sources you trust and are authorized to use. Do not embed
credentials in URLs. External process output is suppressed in normal error messages.
